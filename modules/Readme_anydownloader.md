## ######################################## Steps to install and run ##############################

1. First go to this site and download Ffmpeg software: __https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-full.7z__
2. Extract the zipped file and save it as a folder named: ffmpeg
3. Copy the entire folder created and save it in the C: drive/disk
4. Run CMD as administrator
5. Copy and past this command to add ffmpeg to your PC's environment variables: __setx /m PATH "C:\ffmpeg\bin;%PATH%"__
6. After the success message, now run this software by double-clicking this file: __any-downloader.exe__
7. Copy and paste the video link in the first input field, give the video a name used to save the file. 
8. The downloaded video will be saved in the same folder where this software is.
9. Enjoy free downloader.
